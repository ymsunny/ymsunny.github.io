# Yanming Sun — academic homepage

[Open the website](https://ymsunny.github.io/)

An English academic homepage featuring a research biography, selected publications, education, industry experience, honors, and contact information.

The static website is in `docs/`. GitHub Pages publishes the `main` branch, `/docs` directory. No build step or JavaScript is required.

## Updating the website

- `docs/index.html`: biography, publication entries, education, experience, contact links and structured metadata.
- `docs/styles.css`: typography, spacing and responsive layout.
- `docs/assets/yanming-sun.jpg`: profile photo.
- `docs/assets/papers/`: downloadable research papers.
- `docs/sitemap.xml`: canonical URL and last-updated date.

Edit in GitHub and commit to `main`, or edit locally and push. Changes made in GitHub do not automatically update a local checkout; pull before making local edits.

The owner requested no CV download. Only research-paper PDFs are published. The Ph.D. start date is not specified, so the education entry says “In progress.” NATASHA is listed under NLPCC 2024, with the 2025 proceedings publication year explicitly noted. “Selected for award consideration” is not presented as an award won.
