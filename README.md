# Yanming Sun - Academic Homepage

Live website: https://ymsunny.github.io/

This is a static academic homepage hosted with GitHub Pages from the `main`
branch and the `/docs` directory. No build step is required.

## Site files

- `docs/index.html`: homepage, biography, research interests, papers, honors,
  academic service, and contact information.
- `docs/education.html`: education page.
- `docs/styles.css` and `docs/reading.css`: layout, typography, and responsive
  styles.
- `docs/assets/yanming-sun-budapest.jpg`: original profile photo, framed with
  CSS on the homepage.
- `docs/assets/papers/`: downloadable paper PDFs.
